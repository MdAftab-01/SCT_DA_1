📊 Task 01 – Excel Sales Dashboard (Superstore Sales Data)
🔹 Project Overview

This project involves cleaning, analyzing, and visualizing the Superstore Sales Dataset using Microsoft Excel. The goal was to build an interactive dashboard using Pivot Tables, Pivot Charts, and Conditional Formatting to track business performance and identify high/low-performing areas.

🎯 Objective

Visualize Total Sales

Analyze Profit by Category

Track Sales Trends Over Time

Highlight High and Low Performers using Conditional Formatting

🛠 Tools & Techniques Used

Microsoft Excel

Data Cleaning

Pivot Tables

Pivot Charts

Slicers

Conditional Formatting

Excel Formulas (SUM, SUMIFS, COUNTIFS, IF, VLOOKUP/XLOOKUP)

🔎 Project Workflow
1️⃣ Data Cleaning

Removed duplicate records

Checked and handled missing values

Formatted date columns properly

Converted raw data into structured Excel Table

2️⃣ Data Analysis using Pivot Tables

Created multiple Pivot Tables to analyze:

Total Sales

Total Profit

Sales by Category

Sales by Region

Monthly Sales Trends

3️⃣ Data Visualization

Designed interactive charts:

KPI Cards (Total Sales, Total Profit, Total Orders)

Column Chart (Sales by Category)

Line Chart (Sales Trend Over Time)

Bar Chart (Top Performing Categories/Regions)

4️⃣ Conditional Formatting

Highlighted high-profit categories in green

Highlighted low-profit or loss-making categories in red

Used color scales for performance comparison

5️⃣ Dashboard Creation

Combined all charts into a single dashboard sheet

Added slicers for interactive filtering (Category, Region, Date)

Created a clean and professional layout

📈 Key Insights

Identified the highest revenue-generating category

Detected loss-making sub-categories

Observed seasonal sales patterns

Analyzed profit margins across different regions

💼 Business Impact

This dashboard enables:

Better decision-making through visual insights

Identification of profitable product categories

Improved sales strategy planning

Quick performance tracking using interactive filters

Data Cleaning
